# Personal Website

[brianpurgert2.com](https://brianpurgert2.com) — my portfolio, built with [Nuxt 4](https://nuxt.com) and [Vuetify](https://vuetifyjs.com).

Shipping since 2004, building for 2027. The homepage leads with what's live now
([FPDS.me](https://fpds.me), [Turing's Interface](https://turingsinterface.com),
[Creator to Book](https://creatortobook.com)), then keeps the full build log underneath:
Battlefield 1942 mods at 12, RuneScape bots at 14, two Play Store games at 17,
Miami University, SimpleGSA, the Ruby Discord, Twixer. Press `Ctrl+K` on the site to jump anywhere.

## Development

```bash
npm install
npm run dev      # dev server on http://localhost:81
npm run build    # production build into .output/
npm run preview  # preview the production build
```
